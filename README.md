# Mafari Modified

基于![Mafari](docs/screenshot-home.jpg)浏览器的二次修改项目，针对该项目进行了精简化定制，All by WorkBuddy。

本仓库仅作存档用途。

## 改动项

- 精简设置项中大量的summary注释，界面更清爽
- 去除部分个性化设置
- 优化部分界面与文案排版
- 去除所有首页卡片
- **新增底部导航栏向右滑动缩小隐藏的特性**
- **搜索引擎新增元宝搜索**
- 优化及新增部分场景的动效
- **长按浏览历史可在后台打开、添加到收藏等**
- 修复一些 WebView 适配 bug
- 移除手动更改夜间/日间模式的设置项（在测试中发现其无法映射到 WebView 层，故去除，只保留监听系统深色模式的逻辑）
